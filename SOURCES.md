# Sources

- ffmpeg-static (npm; bundles an ffmpeg GPL build) - used only by the CLI renderer and sample generator.
- yaml (npm, ISC) - session file parsing.
- Windows SAPI text-to-speech - generated the sample voice (synthetic, no real person's voice).
- Sample video: generated by tools/make_sample.js (plain colour background). No third-party media or datasets.
- Music: placeholder generated sine tone (no third-party music).
- No speech-to-text model, no LLM, no external API in the default path.
